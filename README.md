# HangoutRoom
Mini game app for niblings: a cozy virtual bedroom with a fuzzy emo bunny, fidget toys,
dress-up, decorating, an Art Desk for drawing, a Photocard Wall for making collectible bunny cards,
a Fidget Shelf (pop-it, squishy, spinner, slime, clicker cube and a tilt marble maze), a Soccer Field for penalty kicks
(or being the goalie),
a Stage where the bunny performs to 8 original songs (tap to the beat), five animal buddies to choose from,
a Code Lab where she "programs" the bunny with arrow blocks (a first taste of coding), Brain Games (counting,
memory and number puzzles), saved outfits, buddy emotes and a 🌙 night mode.
A family gift; not for sale or public sharing.

## Try it on a computer
Double-click `index.html` (or open it in Chrome). It works offline, with nothing to install.
Since version 1.9 the app is `index.html` **plus the `web` folder** next to it. If you copy it somewhere, copy both.

## Put it on an Android tablet or phone
See `android/README.md`. In short: open the `android` folder in Android Studio, build the APK, copy it to the device and tap to install.

## Which version is this?
In the app: ⚙️ Settings. The version is shown at the bottom (for example "version 1.8").

## Keep progress safe
In the app: ⚙️ Settings → Backup & Restore. Update the Android app by installing over it. Never uninstall first.
Backups from older versions always still restore.
Since version 1.3 a backup also holds the drawings from the Art Desk (you can switch that off in the backup screen
to make the file smaller). Restoring an older backup without drawings leaves the drawings on the device alone.
Photocards (since version 1.4) are always in the backup. They are tiny, because each card is saved as a
short description (outfit, stage, frame, title) instead of a picture.
Soccer, Stage, Code Lab and Brain Games progress (best scores, trophies, keeper gloves, the Golden Mic, puzzles solved), saved looks and night settings are in the backup too.

## Be the Keeper (since version 1.24)
The Soccer Field has two buttons at the top: **⚽ Kick** (taking penalties, as before) and **🧤 Keep** (being the goalie).
It remembers which one was played last.
- In 🧤 Keep, your own buddy (in today's outfit, with keeper gloves) stands in goal and a striker takes 5 shots:
  🐸 **Hop** the bouncy frog (Easy), 🤖 **Bolt** the robot (Medium) and 🦊 **Zip** the speedy fox (Hard).
- **Tap where the ball is going** (or swipe left or right) and the buddy dives there. If the ball hits the buddy, it's a save.
- **Easy is made for the little ones:** the shots are slow and the ball glows, and just tapping the ball catches it.
  They can also change their mind while the ball is flying. On Medium and Hard there is one dive per shot.
  Bolt shows a dotted arrow where the shot will go; Zip sometimes leans one way and shoots the other.
- The shots are the same every time (three sets of 5 per level, taken in turn), so practice pays off. Nothing is lost on a goal.
- Coins: +1 / +2 / +3 per save (Easy / Medium / Hard), +1 more per save with the team kit on, +5 for 5 out of 5.
- Saving all 5 wins that level's **Bronze, Silver or Gold Glove** once. It stands in the Backyard, next to the goal.
- 3 new stickers on the Soccer page: 🧤 First Save, 🧤 Safe Hands (25 saves) and 🥇 Glove Case (all 3 gloves).

## Brain Games (since version 1.25)
Tap the **chalkboard in the Backyard**. There are three games, each with 🐣 Easy (ages 3–5), 🌟 Medium (about 8) and
🧠 Hard (about 11), and 8 puzzles on every level. A game opens on the first puzzle not solved yet; the numbered buttons
jump to any puzzle, and solved ones turn green.
- 🧁 **Snack Stand:** count the treats (Easy, with dots on the answers), add up an order (Medium), or work out change and
  times tables (Hard).
- 🃏 **Memory Match:** find the pairs: 6 cards, 12 cards or 20 cards. The pictures are your own buddy, the other buddies,
  the pets and room things.
- 🫧 **Number Pop:** pop every bubble with the number shown (Easy), pop two bubbles that make 10 or 20 (Medium), or pop
  all the factors of a number (Hard).
- **No timers, nothing lost.** A wrong answer just wobbles and says "Try again!".
- Coins: +2 for each puzzle the first time it is solved, +5 more when a whole level is done. Playing again is free practice.
- In Easy mode every game opens on Easy, and the questions are pictures, numbers and dots (no reading).
- 4 new stickers on the Sticker Book's **Code & Brain** page: 🧁 Snack Shop, 🃏 Sharp Memory, 🫧 Number Popper (8 puzzles
  each) and 🎓 Brain Champ (every level of all 3 games).

## Speed check (since version 1.32)
Nothing new to see; the app just does less work, so the tablet stays cooler and the battery lasts longer.
- **Resting rooms:** a room where nothing is happening used to keep the tablet busy redrawing it 60 times a second
  (the buddy breathing, a lava lamp…). Now those small movements step 5 times a second, all at the same moment,
  and the game loop only runs on the game screens (Soccer, Stage, Fidget Shelf).

## Code Lab (since version 1.13)
Tap the computer desk in the Cozy Loft. Pick a puzzle, then tap arrow blocks to make a "program" for Fuzzy,
and press **▶️ Run**. Fuzzy follows the blocks one at a time (the block that is running lights up) to reach the carrot 🥕.
- **Easy:** arrows only. **Medium:** adds 🔁 repeat blocks (🔁 ×3 then ➡️ = go right 3 times), and only a few blocks fit,
  so she has to use them. **Hard:** adds toy blocks in the way and ⭐ stars to pick up with the 🌟 block.
- If Fuzzy bumps into something, the block that went wrong glows yellow. Nothing is lost: tap a block to take it out,
  fix the program and run it again. There is no timer.
- **✨ My Move** (since version 1.14): a second short row of blocks, **✨ My Move**. Each ✨ block in the program does
  everything in My Move. Tap a row to choose where new blocks go (it gets a gold border). For example: My Move = ➡️ ⬆️
  and the program = 🔁 ×3 ✨ climbs a staircase. The program has room for only a few blocks, so My Move is needed.
- **❓ If** (since version 1.14): puddles 💧 are in the way, and walking into one is a "Splash!" oops. Put ❓ in front of
  an arrow: if a puddle is next, Fuzzy hops over it; if not, Fuzzy just takes a step. 🔁 ×3 ❓ ➡️ handles puddles
  wherever they are.
- **🧠 Challenge** (since version 1.15): 8 harder puzzles that use every block at once. The trick is putting 🌟 and ❓
  *inside* ✨ My Move, so one move handles puddles and stars wherever they are. Each pays 5 coins, plus 10 for the level.
- Other puzzles pay 3 coins the first time they are solved, plus 5 more for finishing a whole level. There are 6 levels
  (6 puzzles each, 8 in Challenge), all open from the start.

## Sticker Book (since version 1.18)
- Tap **📒** at the top of the room. The book has 6 pages (🫧 Fidgets, 🎨 Art & Cards, ⚽ Soccer, 🎤 Stage, 💻 Code Lab,
  🏠 Room & Style) with 66 stickers in all.
- Each sticker is for doing something, for example popping 1,000 bubbles, scoring 25 goals, solving a ✨ My Move
  puzzle, or putting 5 things in the Loft. Many come in steps (1, 2 or 3 little stars on the sticker).
- Stickers she hasn't got yet are grey, with what to do and a bar that shows how far she is. Tap one to see the numbers.
- Each new sticker gives **+2 coins**, once. A sticker is never taken away. A red dot on 📒 means there's a new one to see.
- Stickers for things she had already done before this update all arrive the first time she opens her room.
- The bonus photocards are still there, just as before.

## Seasons (since version 1.17)
- In 🛋️ Decorate there is a **Seasons** tab (its icon is the season right now: 🍂 autumn, ❄️ winter, 🌸 spring, ☀️ summer).
  It has 4 decorations and a wall for each season, such as a Smiley Pumpkin, a Snow Bunny, a Tulip Pot and a Lemonade Stand.
- **Everything can be bought all year.** The current season is just listed first, marked "✨ In season!". Nothing ever
  goes away. The seasonal walls are in the Walls tab too.
- The window in her room and the round window in the Loft change by themselves with the season: falling leaves, snow,
  blossoms or sunshine. The season comes from the tablet's date (autumn = September to November, and so on).

## Shelves and hair (since version 1.11)
- **Shelves:** buy a Little or Long Shelf in the Shop and hang it on the wall. Drag a small thing onto the shelf and it
  sits on top. Move the shelf and everything on it comes along.
- **Hair:** in the Closet's Hair tab, pick a style, then tap a colour circle above. A colour is bought once and works
  with every style.

## For a younger child (since version 1.8)
- **Easy mode:** open her room, then ⚙️ Settings → 🐣 Easy mode. Buttons get bigger, tips are hidden, the room shows labels,
  shops show the cheapest things first (too-dear things are dimmed with a 🔒), and the games start on Easy.
  It is set for each room separately, so the older sister's room stays as it is.
- **Room colour and badge:** each room has a colour and a little picture (🐰⭐💜🦇⚽🎤🎨☁️) on the first screen.
  Change them with ✏️ under the room.
- **Grown-up PIN (optional):** ⚙️ Settings → 🔒 Grown-up PIN. When it is on, making, changing or deleting a room and
  restoring a backup ask for the 4-digit PIN. If you forget it, tap "Forgot PIN?" and answer the sum
  (a calculator helps). The PIN belongs to the device and is not changed by restoring a backup.

## Stage timing
If the notes on the Stage seem to arrive before you hear the beat (this can happen with Bluetooth speakers or slow tablets),
open the Stage and press + next to "⏱️ Sound late?" a few times. Each press waits 20 ms longer. It is saved on that device.

## For whoever works on it next
- `CLAUDE.md`: project rules (for Claude Code and people).
- `PLAN.md`: layout and roadmap.
- `docs/STATUS.md`: where things stand right now.
- `index.html` is the page; `web/app.css` is the look; `web/js/` is the code, one numbered file per part of the app
  (for example `13-soccer.js`). They load in number order.
- `tests/smoke-test.js`: an automatic check of the whole app. With Node.js and Chrome installed, run
  `node tests/smoke-test.js` in the repo folder. It prints "ok" or "FAIL" for each check and saves screenshots in `tests/shots/`.
